About Atlantic Ridge Preserve State Park

Atlantic Ridge Preserve State Park is a Florida state park in Martin County, located near Stuart between U.S. Route 1 and the South Fork of the St. Lucie River. The 4,886 acres (1,977 ha) preserve is administered as a satellite of Jonathan Dickinson State Park and has limited public access, with a gate code required for entry.
